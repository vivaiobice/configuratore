# Vivai Obice — 1.3.8

Nel menu con l'occhio è disponibile **Nomi dei campi**, accanto a Campo, Schema vigneto e Quote.

La spunta controlla soltanto i nomi: campo, filari e quote conservano le proprie scelte di visibilità. I nomi sono visibili all'apertura; **Mostra tutto** riattiva tutte e quattro le voci. La scelta segue la stessa mappa passando tra schermata principale, Campi ed editor mobile.

Il pacchetto contiene l'intera piattaforma, inclusi Conteggi. Caricare il contenuto dello ZIP nella radice del repository come nei rilasci precedenti; versione e query delle risorse sono aggiornate insieme alla 1.3.8.

La modifica riguarda la vista della mappa. Il calcolo dei filari e la stampa mantengono il comportamento della 1.3.7. L'attivazione server della sincronizzazione Conteggi resta pendente; questa consegna non applica migrazioni o pubblicazioni remote.
